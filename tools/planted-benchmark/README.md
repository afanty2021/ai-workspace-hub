# planted-benchmark：回测量具的合成对照检查

借鉴 [Allencake/mit-trader-skill](https://github.com/Allencake/mit-trader-skill) 的 `--planted`
机制：合成市场里埋已知尺寸的优势，加一个只差边项的配对对照市场，把**真实验证管道**跑在
上面，程序化判定「埋的边被检出、对照市场保持沉默」。

## 定位：固定种子回归基线 + 多种子校准（两档）

`run_check.py sr|event|rps|all` 是**固定种子回归基线**：回答一个问题——**在这一个合成
市场上**，这条管道能否检出已知尺寸的边、是否对无边的对照市场保持沉默。用途是防回归
——管道被改坏或改松时变红。

它不回答「误报率多少、多弱的边检得出」。阈值是市场定版后按同一组种子标定的，没有独立
标定集；所以「量具正常」只说明这个尺寸的边在这个市场上被检出了，**不等于**该管道的
历史负结果都可信。要下那种结论跑 `calibrate`（下节，Q-20261125-02 升格落地）。

与 `sector_rotation/permtest.py` 的关系：置换检验是**噪声侧**对照（无优势的策略不应显著
跑赢随机持仓）；本模块是**信号侧**镜像（埋进去的优势必须被检出）。两者合起来才是完整的
量具校验。

## 三态判定

| 结果 | 判读 | 含义 |
|---|---|---|
| 埋边被检出 且 对照市场未通过 | **量具正常** | 仅就本市场、本尺寸而言 |
| 埋边没检出 | **过严或 bug** | 负结果不可信，先修管道 |
| 对照市场也通过 | **过松** | 正结果不可信 |
| 对照样本不足 | **无法判定** | 空样本、有效票太少或 t 为 NaN 都算不足，不算干净 |

## 用法

```bash
conda run -n Quant-3.11 python tools/planted-benchmark/run_check.py all      # 三管道，exit 0=三态全正常
conda run -n Quant-3.11 python tools/planted-benchmark/run_check.py sr --n-perm 200
conda run -n Quant-3.11 python tools/planted-benchmark/run_check.py rps \
    --real-bundle data/research/R20261110-04/rps_bundle.pkl                  # 只读，另报真实数据上的两种 t
conda run -n Quant-3.11 python tools/planted-benchmark/run_check.py calibrate --n-markets 50 --edge-seeds 3 \
    --n-perm 1000 --out-json data/planted-benchmark/calib.json               # 多种子校准，全量约 20 分钟
conda run -n Quant-3.11 python -m pytest tests/test_planted_benchmark.py -q   # 离线，同一条断言链
```

## 多种子校准（calibrate，Q-20261125-02）

- **对照侧**：`--n-markets`（默认 50）个独立噪声市场/宇宙（种子偏移 1000·k，k≥1——0 号
  市场是回归阈值的标定种子，不算独立抽样），各跑同一套管道判定，按出厂对照判据统计
  实测误报率；事件族的 jinniu 接线核对逐市场照跑（读错臂直接抛错，校准统计随跑批作废）。
- **埋边侧**：边强度从弱到出厂扫档（反弹注入 0.2%/1.0%/日五档、动量系数 0.05~0.25 五档），
  每档 `--edge-seeds`（默认 3）个独立种子，检出=该管道的阳性判据全过，逐条判据通过率
  一并报——看哪条判据在弱边上先掉。
- **口径声明**：校准回答的是「这些判据在无边市场上多干净、多弱的边检得出」，供阈值重标
  与「负结果可信度」评估参考。它仍是合成市场（59 票、恒定波动、零停牌除权）上的率，
  不直接等于真实 A 股的率；**测量工具不是闸门**——`calibrate` exit 恒 0、不进单测、
  不替代回归基线的三态判定。
- `--calib-targets event,sr,rps` 可跑子集；SR 置换占大头，赶时间可 `--n-perm 200`
  （判定阈值 α=0.1，p 值分辨率 1/201 仍够）。

### 2026-11-25 首次全量实测（50 对照市场/侧 × 5 档 × 3 种子，n_perm=1000；逐市场原始读数 `data/planted-benchmark/calib-20261125.json`）

| 管道 | 对照侧误报率（实测） | 埋边检出边界（实测） |
|---|---|---|
| event | chuji 1/50、jinniu 4/50、双臂全干净 45/50（联合 10%；2σ 判据名义 ≈5%/臂） | bounce ≥0.8%/日 3/3 检出；0.6% 检出 2/3（t 判据先掉）；≤0.4% 检出 0/3——chuji 检不出 alpha ≲0.6% 量级的反弹边 |
| sr | 六格全过 0/50（出厂判据对照侧干净）；逐格 vs随机 5/50=10%（与 α=0.1 名义精确吻合）、其余格 ≤1/50 | mom_coef=0.05 已 2/3、≥0.10 全检出——SR 阳性判据对极弱边也灵 |
| rps | 价差腿 9/50=**18%**（对照侧最松）、去重叠 t 腿 1/50、双判据全干净 41/50（联合 18%） | mom_coef ≥0.10 全检出；0.05 检出 0/3（价差腿是弱边上的 binding 约束——与它在对照侧最松同源） |

**naive t 膨胀的多种子实证**（rps 对照侧 50 市场）：出厂 validity.py 臂 C 的重叠窗 naive
t 有 **36/50=72%** 在纯噪声市场上过 2（|t| 中位 3.5、90 分位 7.3、最大 11.7）；去重叠 t
同款判据 1/50（中位 0.8、90 分位 1.5、最大 2.8）——「naive t 在噪声市场上就该大面积
显著」由 50 个独立抽样坐实（Q-20261125-05 修根的定量注脚）。

**读法**：①「过松」风险集中在 rps 价差腿（18%）与 event 双臂联合（10%）——单市场对照
沉默 + 2σ 名义 5% 的直觉低估了多判据联合误报；②检出边界给「负结果可信域」的量化下界
——这些管道检不出弱于上表边界的边，历史负结果只在边强于边界的场合可信；③SR 的 vs随机
逐格触发率与名义 α 精确吻合，置换检验的零分布是校准过的。

- `--n-perm`：SR「vs随机」的置换数，默认 1000（p 值分辨率 1/(n+1)），单测用 100。
- `--sr-root` / `--cache-root`：合成数据根目录，默认在 `data/planted-benchmark/` 下。
  **只能落在 `data/planted-benchmark/` 或仓库 `data/` 之外**，指向真实缓存会被写守卫拒绝。
- `--strict`：把「既有管道契约偏差」注记也算失败。默认 exit code 只看三态判定，注记带 ⚠ 打印。
- `--verbose`：透传底层管道的完整表格输出（默认静默）。

## 覆盖的是三条管道的部分部件

| 管道 | 覆盖到的部件 | 埋边市场判据（出厂实测 → 阈值） | 对照市场判据（出厂实测） |
|---|---|---|---|
| SR 检验矩阵 | `run_walkforward` + `momentum_topk`、`perm_test_vs_random`、`paired_block_bootstrap`、两档成本 | 3 行 × 2 档全部 p<0.1（实测全为 0.001） | 不得六格全过（实测 vs随机 0.21/0.66、vs等权 0.35/0.95、vs沪深300 0.04/0.24——六格里有一格偶然通过） |
| stage-bottom | `chuji` 臂的事件研究：信号 → `event_returns` → 分票 alpha 横截面 t | h=5：alpha +1.44%（→>0.7%）、t 10.7（→>5）、正率 100%（→>90%）、信号数 973（→≥300）——实测为 2026-11-25 停牌过滤修根后值 | 35 只噪声票 \|alpha\|<0.5% 且 \|t\|<2（实测 +0.03%、t 0.4） |
| jinniu | `buy` 臂的同一通路，**只判阴性** | 阳性未验证（见下） | 同上（实测 -0.02%、t -0.4） |
| rps 横截面 | `rps_core` 排名；`validity.py` 臂 A（十分位价差）、臂 C（RankIC）；判定用去重叠 t | RPS250 D9−D0 +15.8pp（→>5pp）、RankIC +12.5%（→>3%）、去重叠 t 6.88（→>3.5）——实测为 2026-11-25 预热修根后值 | \|D9−D0\|<1pp（实测 +0.11pp）、\|去重叠 t\|<2（实测 -0.67） |

### 为什么 jinniu 不判阳性

jinniu 的 buy 信号（VAR19）是「下跌链末两连阳」形态加 FILTER(5)，点火很密（合成市场每票
2000 根约 190 次）。在这个反弹埋边市场上，点火日的前瞻窗含注入日的比例是 24.7%，同一
索引域内任意一日的该比例是 25.4%，富集比 0.97——点火与注入窗无关，埋边市场对它不构成
阳性对照。这是**合成市场的性质**，不是量具缺陷：事件研究框架（加载 → 信号 →
`event_returns` → 横截面 t）由 chuji 臂走同一条通路验证，jinniu 的 `d_buy` 行另与独立推得的
buy 信号样本数逐票对拍（读错臂直接抛错）。

以上数字由 `run_check.py event` 输出，可在仓库内复现。**此结论不构成对真实 A 股 VAR19
的任何断言。** 要给 jinniu 做阳性对照，得把边种在它自己的触发形态上（未做，挂 review-queue）。

## 检查发现过、现已修根的既有管道问题（2026-11-25 当日全修，Q-20261125-03/04/05）

以下三处由本检查首次暴露（接线核对独立重数对不上 / 真实 bundle 双口径对拍），当日修根。
指标转为回归哨兵：修法被改回或引入新误删时，对应 ⚠ 注记会重新出现、`--strict` 重新变红。

1. **事件研究的「停牌跳空过滤」跨月误删**（Q-20261125-04，已修）。原过滤用
   `di[nxt] - di[idx] <= gap`，而 `di` 是 YYYYMMDD 整数：跨月时 1201−1130=71 > 阈值 10，
   前瞻窗跨月的样本全被当成停牌剔除——合成市场 h=5 保留率仅 72.4%，真实 600519.SH
   实剔 1039 个（应剔 4 个）。当日修根：两处 `event_returns`（stage-bottom `civil_days`、
   jinniu `_days_from_civil`）与 `sleeve.py` 同写法一并改历法日；受染的全部历史数字
   （stage-bottom / jinniu 家族两张 R 卡两张 EXP 卡）已全市场重算勘误。修后合成市场
   保留率 100.0%，`event_filter_retention` 转为该修法的回归哨兵。
2. **`validity.py` 臂 C 的 RankIC t 是重叠窗口径**（Q-20261125-05，已修）。fwd20 逐日重叠
   （相邻日共享 19 天），naive t 假设逐日独立，零分布约膨胀 √20 倍。当日修根：validity.py
   臂 C 改双口径打印（判定=去重叠 t 相位 0，naive 仅对照）。修根前真实 bundle 旧口径
   RPS250 naive t −16.27 对去重叠 −3.98，膨胀比 ≈4——`t=-15~-17` 不应再当强度证据引用
   （EXP-20261110-03 与 R20261110-04 已补勘误）。本检查的判定始终用去重叠 t，
   `ic_t_overlap` 保留 naive 值用于演示膨胀。
3. **`rps_core` 的上市年数门槛实际是 250+N 根**（Q-20261125-03，已修）。docstring 称
   「≥250 根 bar 才入横截面」，但 `rps_from_ret` 把 `close_count` 作用在 ret 帧上（ret 晚
   N 根）：修根前真实 600519.SH 首个 RPS250 是 2014-07-03（第 500 根）。当日修根：
   `bar_count=close_count(close 帧)` 显式传入（缺省直接抛错，不留静默回退）；修后首个
   RPS250=2013-06-25（docstring 口径），全市场首根 250/250/251，`_warmup_contract`
   转绿。bundle 已重建，R20261110-04 与 EXP-20261110-03 数字已同步重算。

## 合成市场构成

种子全部固定、全链确定性。日期用固定锚点 `ANCHOR`（2026-11-20），不取系统时钟。

**事件族 / rps 共用 59 只**（代码取真实缓存里空闲的 `609xxx` / `309xxx` 段，2026-11-25 核对；
同时满足两条事件管道的宇宙白名单）：

| 组 | 票数 | 生成方式 | 种子 | 用途 |
|---|---|---|---|---|
| `EDGE_BOUNCE`（609900–609911.SH） | 12 | V 型急跌后注入反弹：过去 8 日累计对数收益 < −8% 触发，+1%/日 × 10 日，冷却 8 日 | 1000+i | chuji 的埋边 |
| `EDGE_MOM`（309900–309911.SZ） | 12 | AR(1) 慢趋势埋进对数收益（系数 0.25，衰减 0.97） | 2000+i | rps 的埋边；事件族不判 |
| `NOISE`（609100–609134.SH） | 35 | 几何随机游走 | 4000+i | 对照 |

全部序列带基准漂移 0.0006/日、日波动 0.02、单日对数收益截断 ±9.5%。

**配对**：对照市场与埋边市场同票码、同 eps 种子，只去掉边项——`noise_market_tickers()`
是 `event_market_tickers()` 去掉动量与反弹；SR 的对照宇宙是埋边宇宙去掉三个成员的动量项，
拆掉后逐字节相同。所以「拆掉边项」这个变异得到的恰好是对照市场。

**SR 宇宙**：12 个行业各带一只 ETF 候选（`PLANTED-ETF-00..11`，与指数逐日收益相同），
bench 为 `PLANTED-BENCH`（独立噪声序列，两个宇宙共用）；SI03 / SI05 / SI07 埋动量边
（系数 0.20）。单测与 CLI 的对照判据、`k=3` 持仓都是出厂配置。

**没有漂移对照**。mit-trader 的 NOISE_C（只漂移、零自相关）是单资产时序动量对「敞口匹配
置换零假设」的对照；本库三管道的零假设结构下它没有鉴别力——事件族的 alpha 是信号前瞻均值
减同票基础率，漂移代数抵消；SR 全体同漂移时「vs随机」的零假设与噪声宇宙等价；rps 是横截面
排名。首版带的漂移对照没有一条判据会因它变红，已删除。

## 已知限制

- **回归基线是单次抽样**。对照市场只有出厂这一组种子（换种子须跑 `calibrate`）。「过松」
  判据在换种子时的误报概率已由 2026-11-25 首次全量校准实测（见「多种子校准」节）：多判据
  联合误报率高于 2σ 判据的名义 5%（rps 价差腿 18%、event 双臂联合 10%；SR 六格全过判据
  0/50 但逐格 vs随机 10% 与名义吻合）。
- **SR 的 vs沪深300 行在出厂对照市场上没有被锁住**：基准档 p=0.037，这一格本来就通过。
- **边很强**。SR 埋边宇宙的 CAGR 约 +397%/7 年，chuji 的 h=5 alpha 是 +1.44%/5 日，
  rps 的 D9−D0 是 +16.5pp。本检查说明这些尺寸能被检出，不说明更弱的边能否被检出，
  也不能对接 `backtest.py::power_note()` 的功效口径（合成宇宙只有 12 个行业、59 只票）。
- **价格量级不真实**。动量项的积分是随机游走，合成价格跨约 1e-6 ~ 1e10，成交额是常量名义值。
  含绝对价位或成交额闸门的工具（如 `weak_scan` 的 `MIN_PRICE`）不能直接复用本市场。
- **去重叠 t 只用相位 0**。相位间有波动（埋边市场全相位 7.15~9.03，真实 bundle
  −4.15~−3.25），全相位范围一并打印但不判定。
- run-log 账本不登记 planted 跑批（量具自检不是研究跑批）；不开 EXP / R 卡。

## 开发期的一次性观察（数字未留档，仓库内不可复现）

- 缓坡下跌（−10%/20 日）的市场形状下，链式信号在下跌途中反复点火，对不准注入窗；
  改成 V 型急跌后 chuji 才稳定落在注入段内。
- 给对数价格加弱均值回归锚会让每条序列自身反转（过去涨得多的被拖回），横截面上 RPS
  预测负向未来收益，「噪声」市场出现真实的反转结构。改用有效数字量化解决价格跨数量级的
  落盘问题（定点位舍入会把 1e-7 量级的价格舍成 0）。

## 加第 4 条管道

1. 在 `synth.py` 定一个只对该管道的优势族和一个与它配对的对照（同种子、去边项）。
2. 在 `run_check.py` 写 `check_<name>()`：把埋边和对照两个市场各跑一遍真管道，返回
   `planted_passed` / `noise_leaked` / `sufficient`，用 `_verdict()` 出结论；接线处加一条
   独立推算的对拍（读错臂要抛错）。
3. 在 `tests/test_planted_benchmark.py` 加三件：埋边过、对照沉默；对照换成有边市场必须报
   「过松」；判据逐项违例的参数化用例。每条断言做变异验证。
4. `main()` 的 `runs` 表加一行；更新上文的覆盖表和未覆盖清单。
