# Exploration：事件 alpha 可验收不可收割——组合级 null 必须是同宇宙等权（R20261110-02）

## 核心判断

**tentative**（单一信号族单一执行层形态族的全样本实证；N∈{20,40,150}×填充×止损变体空间内穷尽，未测指数载体），一句话：

**事件研究能验收的 alpha，组合级未必收割得到——单票 BH 口径的超额在换成同宇宙 EW 锚后全面翻转；折损不在信号层，在实现层结构里。**

## 已验证事实（7121 票 2012-2026，预注册主设计 + post-hoc 归因）

| 形态 | 全样本 CAGR | OOS CAGR | maxDD | 单笔均值 |
|---|---|---|---|---|
| EW-universe 基准（同过滤宇宙等权持有） | **+11.41%** | +9.63% | -63.9% | — |
| S1 预注册 gate70×20 仓×deepest | -4.48% | -5.66% | **-82.5%** | -0.06% |
| S2 对照 base20×20 | -1.95% | +1.46% | -75.2% | +0.33% |
| S3 止损-10%（描述性） | -3.46% | -5.26% | -79.2% | +0.11% |
| V3 post-hoc 符号序×N=150（最好） | +1.51% | +1.98% | -54.0% | +0.69% |

- 分年度：S1 对 EW **14 个年度全输**（差距 -4.6~-46pp/年，牛市年差距最大）。
- 归因阶梯（复权口径）：gate70 全事件 +1.999%/笔（U1-U5 过滤后）→ 逐日 RSI 最低子集 +0.214%（预注册规则选中的）→ S1 实现 -0.06% → V3 高分散 +0.69%（仍只有人群均值的 1/3）。
- 上游信号层真实：+2.0-2.6%/20 日/事件、OOS t=28、ADX>67 闸门严格 OOS lift ×2.0（R20261110-01，评审重算口径）——**本研究否决的是收割可行性，不推翻信号层结论**。

## 三层折损（本卡核心结构）

1. **填充规则逆选择（预注册错误）**：deepest-first 把 A1 深度梯度（测于出击事件 RSI 5-50 全谱）外推到 cross-20 人群（RSI 全挤在 20-25）——逐日 RSI 最低子集 +0.21% vs 全人群 +2.0%，6σ 级逆选择；符号序修复后 +0.48%。
2. **槽位配给时间逆选择（结构性）**：20 仓对 7 事件/天×20 日=140 并发需求只服务 14%；槽位在暴跌簇早期被填满（接刀），簇内后续最强反弹信号因满仓被跳过——N=150 高分散仍只实现 +0.69%/笔（24% 接单率）。**事件 alpha 集中在时间簇里，配给机制系统性错过簇内后段**。
3. **集中度**：20 仓弱票组合 maxDD -82.5%（EW 同宇宙 -63.9%），分散不足放大路径风险；止损（S3）更差——防守框架对反弹类入场是纯成本（EXP-20261106-03 预言兑现）。

## 推测

- 三层折损的第三层（集中度）随 N→∞ 收敛于 EW 而非超越 EW（V3/V4 单调改善但顶不过基准）——[推测] 任何「子集择时」形态在该信号族上渐近都不超过母体持有，待第二信号族复核。
- 槽位配给逆选择对「信号成簇型」（暴跌-反弹簇）策略普遍存在，对「信号散布型」（如高股息调仓）可能不重要，[推测] 待对照信号族检验。

## 反方证据 / 限制

- V3（+1.51%/yr，OOS +1.98%，maxDD -54%）绝对为正——若与用户现有组合低相关，卫星仓分散意义存在？但同宇宙 EW 同偏下高 10pp/yr，载体已输给指数形态。
- EW +11.4%/yr 含幸存者偏差，绝对水平高估——但对照双方同偏（同一缓存宇宙），相对结论稳健；真实可投近似载体（微盘/中证 2000 指数基金）长期同样强于本 sleeve 形态。
- 复权近似只处理送转跳落（板别阈值 -12.5%/-22.5%），现金分红未加回（sleeve 侧略低估）；ST 不可从缓存判定=执行边界。
- 宇宙口径注记（2026-11-10 评审）：本表 sleeve 读数为原跑口径（裸 glob 宇宙，含 LOF/指数混入，评审修根后未重跑）——EW 与全部 sleeve 形态**同宇宙同偏差**，相对结论（EW 碾压 14 个年度全输）不受影响，绝对水平两臂同向微偏；工具已接 UNIVERSE_RE 白名单，复跑即净口径。
- 执行层三 bug（YYYYMMDD 年化/不复权穿越送转/填充次序 no-op）全部冒烟读数抓出并修复后才得到上述读数——实现层代码错误的默认方向是把结果打得更差，修好后结论不变。

## 待验证问题

1. 分散指数载体（微盘/中证 2000 类 ETF）对该暴露族的实际可得性与跟踪误差——若用户未来要弱票反转暴露，按 EXP-20261108-03 容量三问评估指数本身。
2. 第二信号族（信号散布型）上复核槽位配给逆选择是否存在（定「簇型专属」还是「配给制普遍」）。
3. 含退市样本的绝对水平复核（左尾被截使 EW 与 sleeve 绝对值均高估）。

## 可迁移结构

**组合级验收两问（事件 alpha → 可执行策略前）**：

1. **正确 null 问**：对照是不是同宇宙等权持有？（单票 BH 会把「弱票池整体上涨」记成策略超额；正结果对 EW 锚、防机会成本低估——EXP-20261107-05 的镜像面）
2. **实现层折损问**：事件均值 → 组合实现的每一层损耗各多少？（本例三层：填充逆选择 -1.8pp/笔、配给时间逆选择 -1.3pp/笔、集中度 DD 放大；信号层 t=28 也救不回）

**预注册≠免检**：预注册规则本身可错（本例 deepest-first 是我预注册的毒性规则）；变体对照首跑必须先验证变体确实不同（本例填充次序 no-op 让 V1/V2 与 S1 逐位相同——错误代码会把「变体无差异」伪装成「规则不敏感」）。
