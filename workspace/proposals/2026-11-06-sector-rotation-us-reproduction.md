# 美股 11 行业 ETF 域：论文复现 + 引擎验证（P0-US）

## 1. 背景与目标

A 股域两轮负结果结案（v1 L0 / v2 L1，OOS 窗口两次消费完毕永久关闭）后，用户拍板换域重开（spec §3.8 第 8 条「新宇宙+显式拍板」路径，2026-11-06）：

- **目标一（引擎验证，首要）**：在论文原始证据域复现 SSRN 4280640 的报告数字（2012-2022 逐年 α，毛 α 均值 12.63%），区分「我们的实现有问题」vs「策略/域本身不成立」。A 股两轮负结果的归因由此获得第二个数据点：若同一引擎在论文域复现出方向一致的 α，引擎无罪；若论文域也复现不出，则要么论文数字不可信（全样本调参嫌疑，spec §1.4 批评②③），要么双方实现都有病灶——两种情形都要单元级证据定位。
- **目标二（论文数字独立复核）**：spec §1.4 对论文的三个批评（无动量对照组/单一窗口全样本调参/preprint 0 引用）中，「数字需独立复现才能采信」由本轮直接回答；「无动量对照组」由 Tier-1 的 L0 动量对照行补上（论文自己没做）。

## 2. 窗口纪律与协议定性（spec §3.8 约束下）

- 本轮定性 = **引擎验证性诊断（探索性，不判定 α、不设确认性闸门）**。依据：美股域是新宇宙，但复现配置的设计本身读过了论文全部结果数字（Table 3 逐年表），任何「过闸式」判定都有选择污染——所以只做并排对照 + 预声明判定域归类，不做 p 值闸门。
- **消费区间 = 2009-01 → 2022-12**（2009-2011 为训练暖机 + 2012-2022 论文交易窗 11 年）。该区间一经复现运行即视为已消费（探索性消费）。
- **尾段 2023-01 → now（≈200 周）保持处女**，作为美股域未来确认窗候选；重开确认性须与第 9 条同构——候选信号族+超参+判据先冻结落档 + 用户显式拍板。结案时落 spec §3.8 第 10 条草案。
- 不消费尾段的执行含义：复现运行 `--slice` 硬编码 2012-01-01:2022-12-31，代码层不暴露尾段开关。

## 4. 与论文的显式偏差清单（复现报告必载）

1. **权重**：等权替代 win-rate/streak 加权（论文公式排版损坏）——方向上低估论文的集中度，α 可能被稀释。
2. **训练更新**：年模型冻结替代每周末增量更新——论文模型的「最新一周」权重更高，冻结模型的标签分布更平滑。
3. **风控**：不实现 Table 2 五条——论文风控只削回撤不增 α（对 α 的影响方向不定，2022 +28.4% 可能部分来自停机规则避开深熊）。
4. **N**：三格网格替代（论文缺失）——最强格与论文实际 N 的偏离不可知。
5. **损失公式**：实现方口径（论文未给公式）。
6. **特征窗**：[t-window+1, t] 含决策周五收盘（修掉 A 股 L1 的 I-3 滞后一档，与论文「周五收盘后采样」对齐；models.py 口径注⑥「v3 重启需重钉边界」的落实）。实现：window_blocks 行块参数化（include_t，§7 第 6 项）或错位配对（blocks[i+1] 配 labels[i]，`upto=t+2` 取末块作 x_now、丢弃无标签末行）——原文引用的 `upto=t+1` 产不出含 t 窗（行块恒 [tj-window, tj-1]，weekly.py:27-28），照字面实现会把未来标签混进训练集，评审 I-1 已修。训练行 tj ≤ t-1（标签=执行周 tj+1 收益，至决策周五收盘已实现）。
7. **标签**：执行窗 open→close 下周收益 ≥1%（周一开盘→周五收盘）——采信 spec §1.1「隐式学习周一开盘与周五收盘两个未来值（不是周五收→周五收）」的读法，与执行 PnL 同口径、与 A 股 L1 引擎原生一致（评审 I-2，**2026-11-06 用户追认 A**；若日后论文原文复核支持周五收→周五收直读，则反向修 spec §1.1 并改此条）。
8. **seed=20261106、CPU、每 fit 前重置**（可复现性口径，论文无此披露）。
9. **ROC 阈值源**：trailing 52 对逐周实际（预测, 已实现标签）对的 Youden J、<26 对回退 0.5（T13/评审 I5 口径）——年首回退期与缓冲跨年模型混用为实现方选择；论文只说「每周动态重估」未披露信息源（评审 I-7，**2026-11-06 用户追认 A**）。

## 5. 判定域（预声明，机械归类）

| 域 | 条件（2012-2022 逐年 α vs SPY(TR)，三格最强格） | 含义 |
|---|---|---|
| **A 域内复现成功** | α 均值 ≥8%/年 且 ≥7/11 年为正 | 引擎验证通过 + 论文方向可复现 |
| **B 方向复现** | **非 A 且 α 均值 >0**（A∪B∪C 无缝覆盖 (α 均值, 正年数) 全结果空间，评审 I-3 补洞） | 引擎通过、幅度/一致性未达 A——归因待分：披露偏差 1/2/3 的消融 vs 论文全样本调参嫌疑，如实并列记录（不预指派，评审 I-5） |
| **C 复现失败** | α 均值 ≤0 | 先引擎/数据逐一单元核对（Tier-1 锚点已绿的前提下指向论文数字），再下结论 |

阈值 8% ≈ 论文 12.63% 的 6.3 折——**锚定折扣（非推导），A/B 边界本质软性**：偏差 1/2 方向偏稀释、偏差 3 方向自认不定，合成折扣只是标定（评审 M-2）；7/11 正年 = 论文 10/11 正的容差放宽到容 3 负年（原「减 1」措辞算术不对，评审 M-1）。任一格单独达 A 即归 A（最强格判定：α 均值最大 → 平手正年数多 → 再平手 N 小），但三格全表披露。年归属 = 执行周 ISO 年（评审 M-3）。

- `MIMOModel(window, epochs, lr)`：输入 = 决策周五**含 t** 的窗口矩阵（include_t 参数化或错位配对，评审 I-1；训练行 tj ≤ t-1，标签=执行周 open→close ≥1%）；masked BCE + λ·金融项；CPU + seed 20261106。

- 测试：种子确定性、mask 不泄漏（掩码外价格翻转逐位不变）、置信弃权二分支、ROC 阈值单调性、含 t 特征边界断言（用 t+1 数据改 t 值应无影响、改 t 数据应有影响）。
