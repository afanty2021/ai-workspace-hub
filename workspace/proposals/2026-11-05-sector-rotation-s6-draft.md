# S6 草案：风控-锚点互斥的消解方案（供拍板）

## 0. 前置声明（先说清楚 S6 不能做什么）

**S6 不改变 v1 的结案结论。** 反事实已证裸 L0 动量信号在 OOS 显著为负（CAGR -15.28%/-23.00%，p→0.92-1.00）——任何消解互斥的方案下，v1 的 k3/momentum/lb1 都是失败，且应该失败。S6 修的是**框架**：让这套引擎/闸门对下一轮信号研究（反转复核、阈值变体、乃至 L1/L2）重新可用，不再把「被 -10% 全停冻结」伪装成「信号无 α」。

## 1. 问题一句话

-10% 绝对亏损全停是**吸收态**（[portfolio.py:42-45](../../tools/sector-rotation/sector_rotation/portfolio.py)，分母=OOS 锚点 NAV），而 2020-07 锚点（S5 数据边界）后接 2021-2024 熊市（沪深300 自锚 -33%）→ 任何做多变体几乎必然触发 → 324 周名义样本实际活跃 77/33 周，配对差 141 周恒 0，闸门测的是冻结路径不是信号。详见结案报告 §6.1。

## 2. 公共条款（无论选哪个方向都生效）

1. **二看惩罚**：OOS 窗口已被 v1 消耗过一次。v2 在同窗口的确认性检验**门槛从 p<0.1 收紧到 p<0.05**（一次性多重消费的简化校正）；并在报告标注「同窗口第二次消费」。
2. **参数冻结纪律**：所有新参数只允许 ①选择窗（2018-10-26→2020-07-03，87 周）网格 ②先验声明——两条来源，二选一写死进预注册行后才准跑 OOS；禁止任何「看了 OOS 再调」。
3. **对照同口径**：闸门路径上主策略与等权/随机对照跑**完全相同**的 overlay 状态（修第三轮 I-A 的对照被包裹未披露问题——v2 起作为协议明文而非事后披露）。
4. **v2 步骤 0（实证前置）**：给 RiskState 加 halt 事件日志，在选择窗重跑 k3 主配置——确认窗内 halt 是否触发（现有 preoos 报告的 MaxDD 是回撤口径，分辨不出绝对亏损口径的触发；主配置 13.23%/胜率 44.8% 疑似未冻结，反向格 -7.32%/MaxDD -20.9% 疑似冻结，需实证）。此步决定方向 A 的参数走「窗内网格」还是「先验声明」。

## 3. 四方向参数化草案

### 方向 A：探针重启（halt 从吸收态改滞回态）

**机制**：触发全停后持币 N 周 → 以 f 仓位探针入场 M 周 → 探针期累计收益 ≥0 则恢复满仓、<0 则再次停 N 周（循环不限次）。

**参数草案（预注册行冻结的完整集）**：

| 参数 | 建议值 | 来源 |
|---|---|---|
| N 停机等待 | 8 周 | 先验（约两个月复盘期）；若步骤 0 证实窗内有触发事件，改窗内网格 N∈{4,8,13} |
| f 探针仓位 | 0.5 | 先验；同上网格 f∈{0.25,0.5} |
| M 确认期 | 4 周 | 先验（月度确认） |
| 循环次数 | 不限 | 无参数化 |

**spec 改动点**：§3.6「全停，人工复盘后重启」→「全停 N 周后 f 仓探针 M 周，确认恢复满仓、否决回到停机」（人工复盘的回测代理）。

**选择窗可预注册性：中-高**。取决于步骤 0：窗内有触发（2020-02/03 疫情崩盘段是唯一候选事件，但 2019 牛市垫高 NAV 后主配置可能未穿线）→ 参数窗内网格实证；无触发 → 全先验声明（仍合规，只是缺窗内验证）。3 参数的调参空间被预注册纪律锁死，无分叉。

**功效恢复估计：部分（约 60-70% 窗口）**。结构估算：2022-2024 熊市中探针多数失败（每次 ~4 周 50% 仓），2024-09 脉冲后探针大概率确认成功恢复满仓至窗末——活跃周 ≈77（首停前）+35-40（探针周，半仓）+~100（2024-10 起恢复）≈ **210-220 周**，可检出 α ≈(5-7%)×√(370/215)≈ **6.6-9.2%/年**（对比现状 11-15%）。

**代价**：①新增 3 参数（纪律已锁）；②熊市反复探针加深回撤（绝对保护变弱——这正是它比现状更接近「人工复盘」语义的代价）；③配对差仍含少量单边停机周（比 141 周少一个量级）。

**v1 配置复判**：仍失败（裸信号为负，重启只是让它继续亏或继续平庸）。

### 方向 B：相对口径（亏损线改基准相对）

**机制**：停机条件从 `nav ≤ start_nav×0.90` 改为 `nav/nav_bench ≤ 1-X`（策略累计落后沪深300 X%）。

**参数草案**：X=10%（先验：与 v1 同数值保持可比）；基准=bench_300（帧内已有，零新数据）。

**spec 改动点**：§3.6 绝对亏损条款 → 相对落后条款；**语义变更需明示**：规则从「保护绝对资本」变为「保护相对表现」——实盘里组合 -30% 但只落后基准 5% 时**不**停机。

**选择窗可预注册性：低**。疫情崩盘中行业篮子与沪深300 同跌，相对落后大概率未达 10% → 窗内无触发事件，X 只能先验声明，无任何窗内验证。且与 vs-沪深300 闸门行存在内生性（风控线锚定的基准=对照组之一）——策略构造上部分向基准看齐，该行 p 值解释力下降，需披露。

**功效恢复估计：接近全额**。等权/动量在 2021-2024 相对沪深300 均未落后 10%（等权反而跑赢）→ 预计 324 周全程活跃，可检出 α ≈ **5.3-7.5%/年**。

**代价**：①保护语义质变（绝对资本保护消失——这是用户实盘意图的核心，需明确接受）；②风控线与对照基准同源的内生披露；③若未来信号确实长期跑输基准（正是要检验的假设），它会停机——检验「跑赢能力」的规则被「跑输即停」截断，存在截尾偏倚（censoring：被迫在表现最差的路径上截断样本）。

**v1 配置复判**：仍失败（裸动量 -15%，相对口径下大概率也触发或即便活跃也 p 惨淡）。

### 方向 C：分层检验（闸门测裸信号，overlay 只报告）

**机制**：闸门路径 = 仅执行闸门（涨停/流动/缺数）+ 成本，**RiskState 关闭**；完整六风控 overlay 路径照跑、照披露（含 halt 统计），但**不进闸门**。升级判据附加一条：裸信号过闸且 overlay 路径未永久停机（或停机可接受由用户裁决）。

**参数草案：零新参数。**

**spec 改动点**：§3.8 检验矩阵改在裸信号路径读取 + 新增「overlay 路径披露段」（halt 触发周/活跃周/冻结期收益）；§3.6 六条完整保留为实盘层。I-A 对照问题按构造消失（裸路径=裸对照）。

**选择窗可预注册性：最高（无参数即无分叉）**。唯一协议决定（闸门挪到哪条路径）是结构性的，不依赖数据。

**功效恢复估计：全额**。裸路径 324 周全活跃（执行闸门拦截个别 asset-week，量级小），可检出 α ≈ **5.3-7.5%/年**。

**代价**：**闸门不再背书实际交易路径**——裸信号过闸但 overlay 会把它停掉的配置，检验说「过」、实盘说「停」。缓解：升级判据的双条件（裸过闸 + overlay 不永久停机）+ 每次 gate 报告并排裸/overlay 两行指标。本质是把「信号有没有边际」和「这套风控下能不能拿到该边际」拆成两个问题分别回答——这更诚实，但用户要接受「闸门过≠可上实盘」。

**v1 配置复判**：仍失败且已知（反事实即裸路径：CAGR -15.28%/-23.00%，p 0.92-1.00）。

### 方向 D：滚动多锚点（窗口切块）

**机制**：OOS 切 K 个不重叠块（如 6×54 周），每块独立锚点（各自 start_nav）独立读闸门，组合规则定总判。

**参数草案**：块长 52/54 周（先验）、K=6、组合规则「≥2/3 块过且合并周差 bootstrap 过」——组合规则本身就是 2-3 个自由度。

**spec 改动点**：§3.8 窗口结构重写。

**选择窗可预注册性：低**。块结构与组合规则无窗内验证手段（窗内只有 87 周，切不出块）；自由度最多。

**功效恢复估计：最差**。单块 n≈52 → 可检出 α ≈ **13-19%/年**（几乎测不出任何现实 α）；合并统计才恢复到整窗水平，但那样切块的稳健性意义又没了。且**单块内 halt 问题原封不动**（熊市块照样冻结）——D 不消解互斥，只是把互斥分散到各块。仅当与 A/B/C 之一复合时才有意义（等价于已计划 T14 的稳健切片，作探索性报告）。

**v1 配置复判**：块结论五花八门但合并仍失败。

## 4. 对比总表

| 维度 | A 探针重启 | B 相对口径 | C 分层检验 | D 多锚点 |
|---|---|---|---|---|
| 新参数 | 3（N/f/M） | 1（X） | **0** | 2-3（块长/组合规则） |
| 选择窗可预注册性 | 中-高（取决于步骤 0） | 低（窗内无触发事件） | **最高（无参数）** | 低 |
| 功效恢复（可检出 α） | 部分：≈6.6-9.2% | **全额：5.3-7.5%** | **全额：5.3-7.5%** | 最差：单块 13-19% |
| 实盘保护语义保留 | **最好**（绝对保护+类人重启） | 质变（只保相对） | 保留但移出闸门 | 中性 |
| 闸门=可交易路径？ | **是** | 是 | 否（双条件缓解） | 是（但块内仍会被冻结） |
| 对照污染（I-A 族） | 大幅减少 | 同左 | **按构造消失** | 原封不动 |
| spec 改动量 | §3.6 一句 | §3.6 语义重写+内生披露 | §3.8 重构+披露段 | §3.8 重写 |
| v1 复判 | 失败 | 失败 | 失败（已知数） | 失败 |

## 5. 推荐（供参考，非捆绑）

**推荐 A+C 复合**：闸门路径 = A（探针重启的单条可交易路径，参数按公共条款 2 冻结）；每次 gate 报告**并排披露** C 的裸信号诊断行（不判定、不进判据）。理由：①闸门背书的仍是「真的会这样交易」的路径（保留你的实盘意图）；②吸收态消除后功效恢复 60-70% 够用（6.6-9.2% 阈值对周频策略本就是合理预期量级）；③裸信号行让「信号边际」与「风控侵蚀」可归因分离，下次失败能立刻分清死因；④零语义质变（对比 B）、零结构重写（对比 D）。若你更看重统计纯净且接受「闸门过≠可上实盘」，纯 C 是参数最少的干净解。
